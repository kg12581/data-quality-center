# 连接配置手册（.env）

所有数据库连接信息（IP / 端口 / 账号 / 密码 / jar）都写在仓库根目录的 `.env`，
规则集里只引用连接名。`.env` 已在 `.gitignore` 里，不会提交；`.env.example` 是模板。

## 1. 命名规则

```
DQ_CONN_<连接名>_<字段>=<值>
```

| 字段 | 说明 |
| --- | --- |
| `TYPE` | `mysql` / `doris` / `oracle` / `postgresql` / `hive` / `spark` / `trino` / `hudi` / `paimon` / `odps` / `jdbc` |
| `BACKEND` | `jdbc`（默认）/ `sqlalchemy`（纯 Python 驱动）/ `pyodps` |
| `URL` | 整串连接串（与下面分字段写法二选一） |
| `HOST` / `PORT` / `DATABASE` / `SCHEMA` / `CATALOG` / `PROJECT` / `SERVICE` | 分字段拼装 |
| `USER` / `PASSWORD` | 账号密码（**建议用服务器环境变量，不要写进仓库里的任何文件**） |
| `DRIVER_CLASS` | JDBC 驱动类名（不写就用该类型默认值） |
| `DRIVER_PATH` | 驱动 jar 路径，多个用路径分隔符（macOS/Linux 用 `:`） |
| `QUERY_ENGINE` | 仅 hudi/paimon：`trino`（默认）/ `hive` / `spark` |
| `DIALECT` | sqlalchemy 后端的 dialect，如 `mysql+pymysql` |

```ini
# 一个连接一段，名字随便起
DQ_CONN_DW_HIVE_TYPE=hive
DQ_CONN_DW_HIVE_HOST=hive-server.example.com
DQ_CONN_DW_HIVE_PORT=10000
DQ_CONN_DW_HIVE_DATABASE=dw
DQ_CONN_DW_HIVE_USER=etl
DQ_CONN_DW_HIVE_PASSWORD=change_me
DQ_CONN_DW_HIVE_DRIVER_PATH=/opt/jdbc/hive-jdbc.jar:/opt/jdbc/hadoop-common.jar
```

规则集引用：

```yaml
sources:
  orders:
    type: hive          # 可省略：.env 里有 TYPE 就用它
    conn: dw_hive       # 对应上面 DQ_CONN_DW_HIVE_*
    table: ods_order_di
```

## 2. 优先级与传入方式

```
代码传入的 conns  >  进程环境变量  >  .env 文件
```

```bash
# ① 用仓库根目录的 .env（默认，本地开发）
python main.py --case 订单数据质量

# ② 指定服务器上的配置（一台机器多套环境）
python main.py --case 订单数据质量 --env /opt/conf/prod.env

# ③ 调度器直接注入环境变量（不落盘）
DQ_CONN_DW_HIVE_HOST=prod-hive DQ_CONN_DW_HIVE_USER=etl DQ_CONN_DW_HIVE_PASSWORD=xxx \
python main.py --case 订单数据质量

# ④ 代码里传（平台集成）
python -c "import common; common.run_case('订单数据质量', conns={'dw_hive': {...}})"
```

## 3. 各类型要点

| 类型 | 默认后端 | 关键点 |
| --- | --- | --- |
| `mysql` / `doris` | sqlalchemy | Doris 走 MySQL 协议，FE 端口默认 9030；装 `PyMySQL` 即可，不需要 jar |
| `postgresql` | sqlalchemy | 装 `psycopg2-binary` |
| `oracle` | jdbc | `ojdbc8.jar`；`SERVICE` 或自定义 `URL_TEMPLATE`（SID 写法） |
| `hive` / `spark` | jdbc | `jdbc:hive2://host:10000/db`；jar 需要 hive-jdbc + hadoop-common + libthrift + slf4j |
| `trino` | jdbc | `jdbc:trino://host:8080/catalog/schema`；查湖表最常用 |
| `hudi` / `paimon` | jdbc | 无独立 JDBC，默认经 Trino（`QUERY_ENGINE=hive/spark` 可切） |
| `odps` | jdbc | 也可 `BACKEND=pyodps`（`pip install pyodps`，用 access_id/access_key） |
| `jdbc` | jdbc | 任意系统：自己给 `DRIVER_CLASS` + `URL` |

```bash
python main.py --list-connectors     # 每种类型的默认 driver、url 模板、端口、需要的 jar
```

## 4. 安全约定

- 密码只走 `PASSWORD` / `PASSWORD_ENV` 对应的**环境变量**；YAML 里不允许写明文密码
- `URL` 里带明文密码会被拒绝（确需写死要显式 `allow_inline_password: true`）
- 报告与日志里**不写**主机、账号、密码；只记录连接名与数据源类型
- 每次运行会打印一行 `[连接] 连接配置：/path/.env；可用连接：...`，方便确认用的是哪份配置

## 5. 排错

| 现象 | 处理 |
| --- | --- |
| `连接配置里没有 xxx` | 连接名拼错，或 `.env` 不在预期位置（用 `--env` 指定） |
| `JDBC 连接需要依赖 jaydebeapi` | `pip install jaydebeapi JPype1`，并确认 `JAVA_HOME` 可用 |
| `NoClassDefFoundError` | jar 不全：hive 需要 hadoop-common / libthrift / slf4j 一起进 `DRIVER_PATH` |
| `JDBC jar 不存在` | 路径写错，或用了 `DRIVER_PATH_ENV` 但环境变量没配 |
| ODPS 报鉴权失败 | `BACKEND=pyodps` 用 access_id/access_key；JDBC 方式要有 odps-jdbc.jar |
