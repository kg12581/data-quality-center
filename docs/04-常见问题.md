# 常见问题（FAQ）

### 运行相关

**Q: `ModuleNotFoundError: No module named 'pandas'`**
`pip install -r requirements.txt`（或先激活虚拟环境）。

**Q: 报告里所有规则都是 `ERROR`，说数据源加载失败**
先跑 `--only <一条规则>` 看具体原因；常见是 `.env` 没配、连接名写错、
jar 缺失（Hive 需要 hadoop-common/libthrift）、或服务端账号密码不对。

**Q: 退出码 2 是什么意思**
配置或参数问题（规则文件写错、变量没定义、连接缺失、`--only` 没匹配到规则）。
错误信息会说明怎么改；退出码 1 才是"数据质量问题"。

### 规则编写

**Q: `${partition}` 报"变量未定义"**
在 `vars` 里定义，或用 `--var partition="..."`；`partition` 有内置默认值 `1=1`，
其他变量必须先定义（报错信息会列出当前可用变量）。

**Q: 指标模式报"要求单行结果，实际返回 N 行"**
指标模式的 SQL 要是聚合查询（`COUNT/SUM/MAX/AVG`，或 `GROUP BY ... HAVING`）。
要查明细行请写 `mode: rows`。

**Q: 快捷方式规则报"数据里没有列 xxx"**
列名写错了（或该列不在数据里）。本地文件会提前校验列名；查库时交给数据库报错。

**Q: rule 里写 `actual` / `result` 会怎样**
有 `expected` 时会被忽略并提示一行（老规则文件可直接复用）；
只有 `actual` 没有 `expected` 会报错（无法判断断言方式）；`--strict-fields` 时一律报错。

**Q: 想允许一点点脏数据**
明细模式加 `threshold: 0.01`（失败率 ≤1% 算通过），说明里会写出实际失败率。

### 数据源与连接

**Q: csv/parquet 能用 SQL 吗**
能。数据会注册成内存 SQLite 表（表名 = `${table}`），用 SQLite 语法（例如正则用 `GLOB`）。
要别的方言就把数据源配成数据库并用 `run_on: source`。

**Q: Doris 要装 jar 吗**
不用。Doris 走 MySQL 协议（FE 端口默认 9030），`pip install pymysql` + `backend: sqlalchemy` 即可。

**Q: Hudi / Paimon 怎么连**
它们没有独立 JDBC，规则集里 `type: hudi`（或 `paimon`），默认经 Trino 查询；
`query_engine: hive|spark` 可切到 HiveServer2 / Spark Thrift。

**Q: ODPS 用 pyodps 还是 JDBC**
都可以：`BACKEND=pyodps`（`pip install pyodps`，access_id/access_key）
或 `BACKEND=jdbc`（odps-jdbc.jar + JDK）。大数据场景通常前者更省事。

**Q: 密码会不会被提交到仓库**
不会。`.env` 在 `.gitignore` 里；规则集只写连接名；报告里只记录连接名与数据源类型。
YAML 里写明文密码会被直接拒绝。

### 其他

**Q: 怎么新增一个用例**
`python scripts/new_case.py --name 订单数据质量 --type odps --conn odps_dw --table ods_order_di`，
然后改 YAML 的 sources / checks。

**Q: tests/ 和 docs/ 可以删吗**
可以。它们不影响运行；`tests/` 是改 `common/` 时的安全网，`docs/` 是文档。
